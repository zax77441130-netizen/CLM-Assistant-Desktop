# CLM Assistant Desktop

Local-first Windows desktop agent foundation for CLM Studio.

This project is not a generic chat UI. It is the foundation for a Windows local work assistant that can intake tasks, plan controlled actions, request approval for dangerous operations, observe results, verify completion, and produce auditable handoff evidence.

Phase 1 is a foundation build. It includes a real Electron shell, a real Python FastAPI sidecar runtime, SQLite initialization, Alembic migration scaffolding, secure IPC boundaries, and tests. It does not connect to a production LLM and does not claim full AI task execution.

## Target

- Windows 10/11 x64
- Electron + React + TypeScript
- Python 3.12 FastAPI sidecar packaged later with PyInstaller
- SQLite local data store

## Security Defaults

- Renderer has no Node integration.
- `contextIsolation` and `sandbox` are enabled.
- Renderer only sees preload allowlist APIs.
- Desktop session token is generated by Electron Main and passed only to Agent Runtime.
- Agent Runtime binds to `127.0.0.1`.
- Generic IPC is forbidden.

## Phase 2 Structured Tasks

Use the Assistant page to select a workspace and run structured development-stage file tasks. Tools accept `workspace_id` and relative paths only. Overwrite requires approval and creates a backup-backed undo record.
